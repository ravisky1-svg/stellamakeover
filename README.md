# Stella Makeover Android App

Android WebView app for the live Stella Makeover salon admin system:

`https://timematters.co.in/salon/`

## Included

- Admin login/session cookies
- JavaScript and DOM storage
- Android back navigation
- Image/PDF file chooser
- WhatsApp, telephone, SMS, email and external link handling
- Loading progress bar
- Offline/error screen
- Responsive Stella Makeover web dashboard

## Open in Android Studio

1. Clone this repository.
2. Open the repository folder in Android Studio.
3. Wait for Gradle Sync.
4. Select an Android phone/emulator.
5. Click **Run**.

## Build APK

Use **Build > Build App Bundles or APKs > Build APKs**.

The debug APK is normally created at:

`app/build/outputs/apk/debug/app-debug.apk`

The live salon URL is set in `MainActivity.kt` as `startUrl`.
